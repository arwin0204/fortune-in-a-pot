# Fortune in a Pot

Entry for the make.fun bounty **Fortune in a Pot** (`u-golden-heron-44-fortune-in-a-pot-ded981e9`): one kind, funny fortune for a houseplant on the windowsill, in 120 characters or fewer.

## Entry

> This windowsill was made for you: expect sunny mornings, one proud new leaf, and a keeper who brags about you daily.

(116 characters, one line.)

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` if set). The output is deterministic: the same text on every run. No network access and no third-party dependencies; Python 3.13 standard library only.
